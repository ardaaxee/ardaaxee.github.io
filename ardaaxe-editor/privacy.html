Privacy Policy

Last updated: September 23, 2026

This Privacy Policy explains how ARDAAXE EDITOR handles information when TikTok integration is used.

1. Information accessed from TikTok

Depending on the permissions approved by the user, ARDAAXE EDITOR may access basic TikTok profile information and permissions required to upload or publish user-authorized video content. The application only requests scopes needed for enabled features.

2. Authentication credentials

ARDAAXE EDITOR is intended to use TikTok's official OAuth authorization flow. The user's TikTok password is not requested or stored by ARDAAXE EDITOR. Access and refresh tokens may be stored locally in the user's own environment when needed to keep the connection active.

3. Video content

Videos selected, generated, or edited by the user may be processed locally by the application. When the user chooses to post to TikTok, the required media and metadata are transmitted to TikTok through the official posting API.

4. Data sharing and sale

ARDAAXE EDITOR does not sell personal information. Information is not shared with advertisers. Data is transmitted to TikTok only as needed for user-authorized TikTok features.

5. Retention

Locally stored tokens, settings, and generated files remain in the user's environment until the user removes them or the application removes temporary files as part of normal operation.

6. Security

Reasonable technical safeguards are used for locally stored authentication data. Users should also secure their device and connected accounts.

7. User control

Users may stop using TikTok integration, revoke granted TikTok permissions where available, and delete locally stored application data.

8. Changes

This policy may be updated as ARDAAXE EDITOR evolves. The current version will be published at this URL.
